## Beta Tester Welcome Guide

### Quick Start Guide (Included in invitation email)

```markdown
# FlixCapacitor Beta Tester Welcome Guide

Welcome to the FlixCapacitor beta testing program! This guide will help you get started.

## Installation

### Method 1: Google Play Store Beta
1. Open invitation email on your Android device
2. Click "Join Beta" link
3. Install from Play Store
4. Done!

### Method 2: Direct APK (if Play Store not available)
1. Download APK from invitation email link
2. Enable "Install from unknown sources":
   - Settings > Security > Unknown Sources (ON)
3. Tap downloaded APK file
4. Tap "Install"
5. Open FlixCapacitor

## First Launch

On first launch, FlixCapacitor will ask for permissions:
- ✅ Storage: Required for library management
- ✅ Network: Required for streaming
- ❌ Other permissions: Optional

Grant permissions to enable full functionality.

## What to Test

### Core Features (Priority 1)
- **Torrent Streaming:** Search, select, play torrents
- **Video Player:** Play, pause, seek, volume, brightness
- **Multi-File Playback:** Select multiple files, auto-play next
- **Library Management:** Favorites, watchlist, history

### Advanced Features (Priority 2)
- **Cloud Sync:** Sign up, sync across devices
- **Search & Discovery:** Browse, filter, search
- **Settings:** Theme, preferences, data management

### Edge Cases (Priority 3)
- **Slow Network:** Test on 3G/slow WiFi
- **Interruptions:** Test phone calls, notifications
- **Background:** Test app switching, background playback
- **Storage:** Test with low storage space

## How to Report Bugs

### Step 1: Check if Already Reported
- Search GitHub Issues: [Link]
- Check Known Issues section below

### Step 2: Gather Information
- Device model and Android version
- App version (Settings > About)
- Steps to reproduce
- Screenshots/videos (if applicable)

### Step 3: Report
- **GitHub:** Create new issue (preferred)
  - Use bug report template
  - Include all requested info
- **Email:** beta@flixcapacitor.app
  - Subject: [Bug] Brief description
- **Discord:** #bug-reports channel

### Good Bug Report Example:
```
Title: [Bug] Video playback freezes after 5 minutes

Device: Samsung Galaxy S23
Android: 14
App Version: 1.0.0-beta.2

Steps to Reproduce:
1. Search for "Big Buck Bunny"
2. Play torrent (1080p)
3. Watch for 5+ minutes
4. Video freezes but audio continues

Expected: Video plays smoothly
Actual: Video freezes at ~5:00 mark

Frequency: Always (tested 3 times)

Screenshot: [attached]
Logs: [attached logcat]
```

## Community Guidelines

As a beta tester, please:
- ✅ Test respectfully and responsibly
- ✅ Provide constructive feedback
- ✅ Keep beta builds confidential (no public sharing)
- ✅ Use legal content only
- ✅ Be patient with bugs (it's beta!)

## Tips for Effective Testing

1. **Test Daily:** Use FlixCapacitor as your main streaming app
2. **Try Edge Cases:** Slow network, low storage, old devices
3. **Take Notes:** Document unexpected behavior
4. **Be Specific:** Detailed reports are most helpful
5. **Screenshot Everything:** Visual proof is valuable
6. **Test on Multiple Networks:** WiFi, 4G, 3G
7. **Battery Life:** Monitor battery drain
8. **Update Regularly:** Always use latest beta build

## Weekly Rhythm

**Monday:** New build release + update email
**Wednesday:** Mid-week check-in (Discord)
**Friday:** Bug triage + planning for next week

Stay engaged, check Discord, respond to update emails.
```
